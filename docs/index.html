THE CONSOLE BETWEEN THE GAMES

Make it yours.
Keep it yours.

A shared computer can still hold a personal arcade. Your player, your favorites, your next attempt.

01

Pick up where you paused.

Continue a recovery snapshot or use one of five manual slots. Pause on focus loss or controller disconnect keeps a break from becoming a lost run.

02

A little household rivalry.

Separate local players, achievements, and records by mode and difficulty. Compare a new best without mixing everyone’s progress.

03

Your progress stays local.

A local database, browser preferences, and backups you control. No online account. Export your data or restore player copies when you need them.

# From the repository root

Keep the terminal open. Ctrl+C stops the console.

BEFORE YOU PRESS START

A few useful things.

Does it work offline?

Yes, normal play works offline after dependencies are installed and the frontend is built. Game artwork, models, and fonts are bundled. Initial setup needs Internet access.

Is there an installer?

Arcade Nexus runs from source with Python and Node.js tooling. It does not distribute a desktop executable or APK.

Can I use a controller?

The console supports standard browser gamepads, menu navigation, text entry, remapping, and dead-zone settings. Each game’s launch screen explains its controls.

How do I keep my progress?

Use Settings to export a backup, preview an import, or manage rotating server snapshots. Export from the same browser origin to include preferences and pending results. Import preserves existing players by creating copies.
