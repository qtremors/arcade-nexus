# Local validation

Validated on `ag-dev`, 2026-10-14, Linux, Python 3.12.14, Node 24.19 and Chromium 151.0.7922.173. The final `python scripts/check.py --browser` run passed. No CI/CD configuration was created.

- **117 backend tests passed**, including migrations/rollback, concurrent immutable receipts, ownership, query budgets, full-history filters, snapshot retention/clock rollback, malformed wrappers, copied save UUIDs, reserved-start restoration, corrected legacy totals and atomic terminal recovery cleanup.
- **198 frontend unit tests in 26 files passed**, covering deterministic games/saves, input/frame limiting, Full HD caches and 3D resources, quotas/live preferences, backup mapping, background work, controller handover/focus, audio failures/idle suspension, legacy Raptor configuration and delayed-record races. Audio regressions also passed with shuffled test order.
- **All 43 real-server Chromium browser journeys passed in the final run**, including all eight games, saves/Continue, Flight ships/races/surveys, time records, two-tab results/profile isolation, backups/previews, controller input, Full HD buffers and 3D antialiasing. New checks cover quota-safe settings/live export, controller focus across disclosures and reduced-motion animation completion. An initial focus test needed an explicit wait for the lazy Settings page; its corrected targeted checks and the subsequent full run pass.
- Axe-core WCAG 2 A/AA and 2.1 AA checks passed on Home, Games, Favorites, Progress, Profile and Settings at 1440×900 and 720×450 (a 200%-zoom-equivalent layout). This covers those twelve combinations; actual zoom and assistive-technology use remain manual.
- Ruff, ESLint, TypeScript, the production build, changed-file formatting and whitespace checks passed. The optional shared Three.js chunk retains Vite's large-chunk advisory. Eager entry plus every module preload totals **452,115 raw bytes** (main script **388,982**; independent gzip sum **143,510**), an increase of **1,615 raw bytes** from the preceding reliability build. CSS, fonts and lazy routes are excluded; this is not a launch-time measurement. See [startup sizes](performance/startup-deep-review.json).
- Offline lock validation passed; frontend manifest/lock dependencies and the backend locked runtime export agree. SVG resource checks, PNG integrity/dimensions, embedded GLB structure and stylesheet syntax checks passed. No fresh remote vulnerability-advisory scan is claimed.
- A real development-launcher probe with an isolated database reached readiness and exited with code 0 on SIGTERM; both ports 8000 and 5173 closed. The pre-fix probe left Vite on 5173. Historical checks on 2026-10-12 used `UV_OFFLINE=true`, preserved an isolated profile across production restarts, rejected an occupied port with exit code 1, released the production port on SIGTERM, recovered the latest server snapshot after browser SIGKILL, and observed no non-loopback requests with external requests blocked. Those earlier checks were not all repeated here.
- A real Chromium system-audio probe created zero contexts for muted gestures, ran for an audible cue, suspended after idle, resumed for a new cue and suspended on mute. This verifies API behavior, not battery-life gains.

Tests and probes used isolated data, not the user's database. Browser gameplay ran with SwiftShader software WebGL. Existing performance samples and visual/resource comparisons remain in [PERFORMANCE.md](PERFORMANCE.md); they were not remeasured as native GPU results during this reliability review. The six 2D games previously measured approximately 60 FPS in short software samples; the 3D software samples fell below 60 FPS while preserving detail.
